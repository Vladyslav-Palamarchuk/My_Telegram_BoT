# Telegram Shop Bot

Проект асинхронного Telegram-бота для автоматизації замовлень та збору заявок.

## Технологічний стек
* Мова програмування: Python 3.10+
* Бібліотека: aiogram 3.x
* База даних: SQLite3
* Конфігурація: python-dotenv

## Основний функціонал
1. Інтерактивне меню (Reply та Inline кнопки).
2. Збір даних через FSM (номер телефону).
3. Збереження заявок у базу даних SQLite.
4. Модульна архітектура (розділення логіки на окремі файли).

## Інструкція із запуску
1. Клонувати репозиторій.
2. Встановити бібліотеки: `pip install aiogram python-dotenv`.
3. Створити файл `.env` у корені проекту та додати свій токен: `BOT_TOKEN=ваш_токен`.
4. Запустити файл `main.py`.
